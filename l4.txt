TCP SYN cookie
‣ SYN 플러드 공격에 저항하는 데 사용되는 기술입니다(거의 100%! 근데 심플!).

‣ Invented by Daniel J. Bernstein

‣ Half-opened 상태를 발신자에게 마이그레이션! → 어떻게?!

‣ SYN번호는 랜덤한 번호로 시작...! ⇒ 이를 Ack번호로 부터 유도하자
 •서버의 SYN 넘버는 'HASH(SYN)'
 •이후 클라이언트의 ACK는 'HASH(SYN)+1'
  → 이는 클라이언트의 SYN에서 다시 계산할 수 있는 값...!

                                         Here, we assume the hash function as HASH(x) = (x + 12345)%10000




증명
‣ 클라이언트는 [S 1000 / A ----] SYN을 전송

‣ 서버는 다음을 포함하는 SYN/ACK을 반환
 •Get the hash(1000) = 3345
 •Send it as its ACK value, i.e., [3345 / 1001]

‣ 클라이언트는 ACK [1001 / 3346] 반환

‣ 'ack' 패킷을 수신한 후 서버는 ACK 값의 유효성을 검사합니다.
 •Get the hash(SYN-1), i.e., hash(1001-1) = 3345.
 •Compare it with 'ack-1', i.e., (3346-1) == 3345.
 •동일한 경우 이 세션이 올바른 세션으로 판단할 수 있습니다.



‣ 서버는 값을 저장할 필요 없이 핸드셰이킹 프로세스를 처리할 수 있습니다.

#!/usr/bin/python3

import sys
from time import time
from scapy.all import sniff

ip_to_ports = dict()

# Nr of ports in timespan seconds
nr_of_diff_ports = 3
portscan_timespan = 100

def detect_portscan(packet):
    ip = packet.getlayer("IP")
    tcp = packet.getlayer("TCP")

    # Remember scanned port and time in unix format
    ip_to_ports.setdefault(ip.src, {})\
               [str(tcp.dport)] = int(time())

    # Source IP has scanned too much different ports?
    if len(ip_to_ports[ip.src]) >= nr_of_diff_ports:
        scanned_ports = ip_to_ports[ip.src].items()

        # Check recorded time of each scan
        for (scanned_port, scan_time) in scanned_ports:

            # Scanned port not in timeout span? Delete it
            if scan_time + portscan_timespan < int(time()):
                del ip_to_ports[ip.src][scanned_port]

        # Still too much scanned ports?
        if len(ip_to_ports[ip.src]) >= nr_of_diff_ports:
            print("Portscan detected from " + ip.src)
            print("Scanned ports " + ",".join(ip_to_ports[ip.src].keys()) + "\n")

            del ip_to_ports[ip.src]

if len(sys.argv) < 2:
    print(sys.argv[0] + " <iface>")
    sys.exit(0)
